# Basic Layer

Implement, test and document the first version of the layer module. This module must include the abstract class layer from which will derive all other layer classes. Also implement the dense layer class.

My suggestion of the structure is something like that:

```
src/
  |
  +--- mAbstractLayer.f90
  |
  +--- mDenseLayer.f90
```

```fortran
module mAbstractLayer
    ! Program here the Abstract layer class. Make the class public.

    public :: AbstractLayer

    type AbstractLayer ....
end module mAbstractLayer
```

```fortran
module mDenseLayer
    ! Program here a denseLayer derived from the Abstract Layer
    use mAbstractLayer, only: AbstractLayer

    public :: DenseLayer

    type, extends(AbstractLayer) :: DenseLayer
end module mDenseLayer
```

Implement, test and document.
