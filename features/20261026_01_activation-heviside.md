# Heaviside activation function

https://en.wikipedia.org/wiki/Heaviside_step_function

Implement, test, and document the heviside activation function:

$$
H(x) =
\begin{cases}
0, & x < 0, \\
1, & x \geq 0
\end{cases}
$$
